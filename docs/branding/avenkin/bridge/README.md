# Avenkin Bridge exploration

Concept previews for the proposed Avenkin and Avenkin Office identity. Existing application assets are unchanged.

- `02-bridge-variants.png`: Soft arch, Open span and Low bridge comparison.
- `03-open-span-family.png`: Further development of Open span in light, dark and monochrome appearances.
- `generation-prompts.txt`: Exact prompts used with the built-in imagegen tool.

The selected direction is Open Span: a rounded arch with a crossbar joined to the left leg and interrupted before the right leg. The opening is the shared signature. Avenkin has separated feet; Office adds a thin joined foundation so the applications differ by silhouette as well as colour.

Palette: warm orange `#E77F47`, warm ivory `#F6F2EB`, charcoal `#202B2D`.

The generated boards illustrate the direction. Their small samples are illustrative, not measured export tests. The `open-span/` directory now contains a precise vector reconstruction, 1024px exports, and a review sheet with actual 16, 24, 32, 48 and 64px samples. See its README for export and usage details.
