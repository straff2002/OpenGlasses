# Parts — SLP99UHVK series

Every number here is printed in the manuals. Source: SLP99UHVK Service Manual p.3 (OPTIONAL
ACCESSORIES — ORDER SEPARATELY) and TABLE 38 (Conversion Kit & High Altitude Requirements), which
the Installation Instructions repeat. Cabinet widths map to models as `models.md` lists them:
B = 070XV36B, C = 090XV36C / 090XV48C / 090XV60C / 110XV60C, D = 135XV60D.

Nothing here is a stock list or a price. It says what the book says the part is and what it fits;
availability is base's answer.
